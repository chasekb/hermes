# Rubric template

Criteria:
- correctness
- completeness
- instruction following
- risk
- future-routing usefulness

For each criterion, record:
- score: 1-5
- anchor: the score anchor used
- rationale: one short sentence

Decision threshold:
- route-to-open-code if the OpenCode lane is competitive on correctness and clearly better on cost/latency or response quality for the prompt class.
